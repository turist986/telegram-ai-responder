Приложение Telegram (api_id)
По умолчанию каждый аккаунт получает собственное приложение — не потому что общий api_id выдаёт связь аккаунтов (Telegram сам использует один api_id для всех пользователей официальных клиентов), а чтобы не зависеть от одного приложения сразу для многих аккаунтов. Выбор существующего пула экономит проход через my.telegram.org: код/CAPTCHA не потребуются, вход в Telegram начнётся сразу. Прокси, сессия и профиль устройства всё равно остаются уникальными для каждого аккаунта. Лимит на пул — {{ pool_limit }} аккаунтов (меняется в «Настройки» → «Защита аккаунтов»).

или одной строкой (host:port:логин:пароль, логин:пароль@host:port, socks5://…):
Требования к прокси: статичный (sticky) IP, не ротирующийся; страна — та, где менеджер обычно заходит в Telegram; отдельный прокси на каждый аккаунт. Перед стартом прокси проверяется на доступ к серверам Telegram. Менеджер должен быть рядом: ему придут два кода в Telegram (сначала для my.telegram.org, затем код входа).
