Перетащите сюда архивы или нажмите, чтобы выбрать
.zip и .rar; в одном архиве может быть одна или много папок tdata
    Прокси (обязательно)
    По строке на аккаунт, в том же порядке, что и аккаунты (порядок — по названиям папок: 1, 2, 10…). Любой формат: host:port:логин:пароль, логин:пароль@host:port, socks5://…. Один прокси — один аккаунт. Если аккаунт уже есть в таблице и у него сохранён прокси, поле можно оставить пустым.
    Идентификаторы (необязательно)
    По умолчанию берутся из названий папок (1\tdata → 1) или из имени архива, если tdata лежит в корне. Чтобы задать свои — по строке на аккаунт, в том же порядке.
    Пароли (если нужны)
    Пароль применяется ко всем аккаунтам в этой загрузке; у аккаунтов с разными паролями импортируйте отдельными пачками. Пароли нигде не сохраняются.
    Как это работает: для каждого аккаунта создаётся новый отдельный сеанс (свой ключ; в Telegram он виден как отдельное устройство и не делит ключ с Telegram Desktop), все подключения идут через прокси аккаунта. Аккаунты входят по одному с паузами. Перед импортом закройте Telegram Desktop с этими профилями — иначе Telegram может аннулировать ключ. Импортированные аккаунты создаются выключенными — включите автоответчик через 30–60 минут. Кеш профиля (user_data, эмодзи) при распаковке пропускается, поэтому большие архивы допустимы.
