# Зависимости импорта TData (папка профиля Telegram Desktop) ставятся СКРИПТОМ:
#
#     python scripts/install_tdata_deps.py
#
# Почему не `pip install -r`: opentele тянет пакет tgcrypto, который собирается из
# исходников и требует компилятор C++ (Microsoft C++ Build Tools / build-essential) —
# на чистом сервере установка падает. Скрипт ставит opentele без tgcrypto (--no-deps),
# а PyQt5 — отдельно; вместо tgcrypto проект использует чистый Python-шим
# (app/services/_opentele_compat.py).
#
# Ручной эквивалент:
#     pip install PyQt5
#     pip install --no-deps opentele==1.15.1
